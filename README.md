
# slowfetch

slowfetch is a little fetch program written in C. I decided to use it to test my skills basically, and I'm going to update it whenever I have enough knowledge for it.

# Build

To build it, you can just cd into src, and run: <br>
```bash
gcc -o slowfetch main.c
```
Then, if you want to use it globally, just run: <br> 
```bash
cp slowfetch /usr/bin/slowfetch
```
